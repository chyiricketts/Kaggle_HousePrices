# House Prices - Advanced Regression Techniques

Kaggle competition: predicting house sale prices using the Ames Housing
dataset. The goal is to predict the final price of residential homes
based on 79 explanatory variables.

[Competition Link](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

---

## Results

Final submission ranked **1038 out of 4748** (top 22%) with a public
leaderboard RMSE of **0.12329**. Note that the top ~100 submissions on
this competition are widely known to use leaked labels, so the realistic
honest leaderboard starts around rank 100 with a score of ~0.116.

The OOF RMSE and public score were nearly identical (difference of
~0.0003), which suggests the cross-validation setup was reliable and
the pipeline generalises well to unseen data.

## Approach

### Data Cleaning

Missing values were handled using domain knowledge rather than blind
imputation. For example, a missing PoolQC does not mean the data is
missing -- it means the house has no pool. These were filled with
'None' or 0 accordingly. LotFrontage was imputed using the median of
the same neighbourhood, which is more meaningful than a global median.
Ordinal columns like ExterQual and KitchenQual were mapped to integers
preserving their natural order rather than label encoded arbitrarily.

### Feature Engineering

New features were created in a separate notebook and saved alongside
the cleaned data. The main additions were:

- Area aggregates: TotalSF, TotalBath, TotalPorch
- Time features: HouseAge, RemodAge, WasRemodeled, IsNew
- Interaction terms: OverallQual x GrLivArea, OverallQual x TotalSF
- Binary flags: HasPool, HasGarage, HasFireplace, Has2ndFloor
- Ratio features: LivAreaRatio, BsmtFinRatio
- Log transform applied to highly skewed numerical features

Two versions of the feature engineered data were saved -- one keeping
all features for tree models, and one dropping the component columns
(e.g. 1stFlrSF, 2ndFlrSF) that were aggregated into TotalSF, to avoid
multicollinearity in the linear models.

### Models

All gradient boosting models were tuned with Optuna using 200 trials
and evaluated with 5-fold cross validation. Out-of-fold predictions
were saved for each model to enable honest ensemble weight optimisation.

### Ensembling

Four ensemble strategies were compared using OOF predictions:
simple average, inverse-RMSE weighted average, grid search optimised
weights, and Ridge stacking. The optimised weights approach performed
best. Blending was done in log space before reversing the
log transformation, which better matches the competition metric.

## How to Reproduce

### 1. Clone the repo
git clone https://github.com/chyiricketts/Kaggle_HousePrices.git

### 2. Set up the environment
conda env create -f environment.yml
conda activate houseprices_env

### 3. Download the data
Download from the competition page and place in data/raw/:
- train.csv
- test.csv
- data_description.txt
- sample_submission.csv

### 4. Run in order
1. clean.ipynb
2. feature_engineering.ipynb
3. model notebooks in any order
4. ensemble.ipynb
5. evaluate_submissions.ipynb
